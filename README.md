# The Tiny Handbook

A colorful, playful 100-chapter guide to building a Unity game. Open index.html in a modern browser.

Each chapter has four guided steps, a tiny activity and a question at every step, simple word cards, and a 10-question multiple-choice quiz with feedback and chapter stars. Search the adventure map to find any chapter.

The chapters are learning plans; some features are ideas to add to the Unity project later. The handbook works offline; optional web fonts use an internet connection.
